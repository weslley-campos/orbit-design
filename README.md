# Orbit design

The design workspace for Orbit, a personal expense manager with optional sharing with family members.

```bash
python3 design/serve.py
```

Open [localhost:4173](http://localhost:4173). Python 3 is enough to preview the workspace; fonts, icons, strings and legal documents are included.

```bash
node design/check.mjs
```

See [the workspace guide](design/README.md) for editing, prototype flows, export/import and synchronizing with the [Orbit application](https://github.com/weslley-campos/orbit). Design specs live in [docs/specs](docs/specs).
