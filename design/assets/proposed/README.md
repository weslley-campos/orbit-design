# Proposed icons

Orbit has no icon set for these yet. They are design proposals, not app resources; the workspace marks every use as a proposal.

- Source: Lucide (https://lucide.dev), project lucide-icons/lucide
- Licence: ISC (https://github.com/lucide-icons/lucide/blob/main/LICENSE)
- Icons: ic_mail_check, ic_users, ic_clock, ic_x, ic_copy, ic_share, ic_shopping_basket, ic_utensils, ic_car_front, ic_fuel, ic_heart_pulse, ic_ticket, ic_zap, ic_wifi, ic_bell, ic_chevron_right, ic_chevron_down, ic_triangle_alert, ic_ellipsis, ic_credit_card, ic_landmark, ic_shield_check, ic_circle_check, ic_search, ic_plug, ic_circle_help, ic_palette, ic_moon, ic_languages, ic_banknote, ic_lock, ic_key_round, ic_download, ic_file_text, ic_log_out, ic_trending_up, ic_trending_down, ic_calendar_days
- Referenced as `proposed.drawable.ic_<name>` in `catalog/screens.decl.json`; tinted with the node color (stroke `currentColor`).

The navigation bar's Home, Charts and Wallet pairs (`ic_home_filled`, `ic_home_outline`, `ic_chart_pie_filled`, `ic_chart_pie_outline`, `ic_wallet_filled`, `ic_wallet_outline`) come from Heroicons (https://heroicons.com, MIT, https://github.com/tailwindlabs/heroicons/blob/master/LICENSE), like the Settings cog in core-ui: filled when selected, outlined otherwise.
