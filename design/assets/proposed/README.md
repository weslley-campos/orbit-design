# Proposed icons

Orbit has no icon set for these yet. They are design proposals, not app resources; the workspace marks every use as a proposal.

- Source: Lucide (https://lucide.dev), project lucide-icons/lucide
- Licence: ISC (https://github.com/lucide-icons/lucide/blob/main/LICENSE)
- Icons: ic_mail_check, ic_users, ic_clock, ic_x, ic_plus, ic_copy, ic_share, ic_shopping_basket, ic_utensils, ic_car_front, ic_fuel, ic_heart_pulse, ic_ticket, ic_zap, ic_wifi, ic_bell, ic_house, ic_receipt_text, ic_target, ic_chevron_right, ic_chevron_down, ic_triangle_alert, ic_ellipsis, ic_chart_no_axes_column, ic_credit_card, ic_user_round, ic_landmark, ic_shield_check, ic_circle_check
- Referenced as `proposed.drawable.ic_<name>` in `catalog/screens.decl.json`; tinted with the node color (stroke `currentColor`).
